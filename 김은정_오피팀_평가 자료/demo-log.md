## 상세 실행 결과

### 기능 1: 갭투자 가능 지역 - 부대비용 자동계산
- **입력**: 평촌 귀인마을 우성, 매매가 2억 3,000만, 전세가 1억 8,000만, 토허제=아님
- **계산 과정**: 갭 5,000만 / 취득세 253만(2.3억×1.1%) / 중개비 92만(2.3억×0.4%)
- **출력**: 실투자금 5,345만 (갭+취득세+중개비)

### 기능 2: 토허제 지역 - 실거주 필요자본 자동계산
- **입력**: 금천 독산 래미안, 매매가 3억 1,000만, 전세가 2억 2,000만, 토허제=해당
- **계산 과정**: 취득세 341만(3.1억×1.1%) / 중개비 124만(3.1억×0.4%)
- **출력**: 필요자본 3억 1,465만 (매매가+취득세+중개비) — 토허제라 전세 불가, 전액 필요

### 기능 3: 5억 이하 소형 아파트 계산
- **입력**: 용인 수지 현대, 매매가 2억 8,000만, 전세가 2억 1,000만, 토허제=아님
- **출력**: 실투자금 7,420만

### 기능 4: 실투자금 기준 정렬 비교
- 1위: 평촌 귀인마을 [갭투자] → 5,345만
- 2위: 용인 수지 현대 [갭투자] → 7,420만
- 3위: 중랑 면목 현대 [토허제] → 2억 5,375만
- 4위: 금천 독산 래미안 [토허제] → 3억 1,465만

### 기능 5: Next.js 대시보드 빌드
- `npm run build` 성공 (3.3초 컴파일)
- 정적 페이지 4개 생성: `/`, `/30pyeong`, `/seoul`, `/under5`
- 각 페이지에서 ApartmentCard 컴포넌트를 통해 자동계산 결과가 UI에 표시됨
