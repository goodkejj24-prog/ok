나는 이 에이전트(또는 자동화 프로그램 또는 n8n 워크플로우)의 평가 자료를 제출해야 해. 아래 순서대로 진행해줘.

## Step 1. 프로필 작성

아래 항목을 정리해서 agent-profile.md 파일로 작성해.

### 1. 해결하려는 문제

- 실무에서 겪고 있는 Pain Point
- 현재 업무 처리 방식 (As-Is)
- 에이전트가 바꿔주는 방식 (To-Be)

### 2. 설계 구조  

- 핵심 기능 목록
- 워크플로우 흐름 (어떤 순서로 작동하는지)
- 사용한 주요 도구/스킬/MCP 서버 목록

### 3. 기술적 특이사항

- 구현하면서 어려웠던 점과 해결 방법
- CLAUDE.md에 넣은 핵심 지시사항 요약

## Step 2. 핵심 기능 실행 데모

에이전트(또는 자동화 프로그램 또는 n8n 워크플로우)의 핵심 기능을 하나씩 실제로 실행해. 각 기능마다:

1. 어떤 기능인지 한 줄 설명
2. 실제 실행
3. 실행 결과 요약

모든 실행이 끝나면 아래 형식으로 demo-log.md 파일을 작성해.

| 기능명 | 실행 성공 여부 | 생성된 결과물 | 비고 |

실행 중 생성된 결과물 파일도 모두 보관해.

## Step 3. 발표자료 PPT 생성

아래 순서대로 진행해줘.

### 3-1. 소속/이름/직급 확인

PPT에 들어갈 정보를 알려줘:
- 소속 (예: OKH 인재개발팀)
- 이름
- 직급 (예: 사원, 대리)

### 3-2. generate_ppt.js 실행

프로젝트 루트에 generate_ppt.js 파일이 있는지 확인하고, 없으면 아래 경로에서 복사해줘.
(파일은 별도 제공)

## Step 4. 제출 폴더 정리

프로젝트 루트에 "홍길동_소속팀_평가 자료" 폴더를 만들고 (홍길동과 소속팀 자리에 내 이름/소속을 넣어), 아래 파일을 모두 넣어줘.

1. agent-profile.md
2. demo-log.md  
3. CLAUDE.md (프로젝트 루트에서 복사)
4. Step 3에서 생성된 ppt 파일
5. Step 2에서 생성된 결과물 파일 전부

혹시 이 평가 자료 작성 과정에서 나에게 확인할게 있으면 물어봐줘. 프롬프트 실행 완료 후에 결과물이 잘 나왔는지 내 확인을 받고 prompt.txt와 generate_ppt.js를 제거해줘.
